## 🚀 Usage
### Git Commands

1. **Initialize a repository**
   ```sh
   git init  # Initialization
   ```
2. **Add files to staging**
   ```sh
   git add -A  # Add all files
   git add <filename>  # Add specific file
   ```
3. **Commit changes**
   ```sh
   git commit -m "message"
   ```
4. **Push changes to remote repository**
   ```sh
   git push <repository-url>
   git push -f -u origin master  # Push with force and set upstream
   git push -f -u origin <branch-name>
   ```
5. **Check status and logs**
   ```sh
   git status  # Track changes
   git log  # Check commit history
   ```
6. **Manage credentials**
   ```sh
   git credential-manager erase  # Remove all credentials
   ```
7. **Set user details**
   ```sh
   git config --global user.email "you@example.com"  # Add email
   git config --global user.name "Your Name"  # Add name
   ```
8. **Change git directory and add remote**
   ```sh
   git config --global --add safe.directory "directory full path"
   ```
9. **Check git origin status**
   ```sh
   git remote -v
   ```
10. **Add upstream branch into git**
    ```sh
    git push --set-upstream origin master
    ```
11. **Pull changes from remote**
    ```sh
    git pull origin main --rebase
    ```
12. **Change branch**
    ```sh
    git checkout origin main  # Switch to main branch
    ```
